# nahuelgenchi.github.io

The root of Nahuel Genchi's GitHub Pages sites. It holds no site of its own: its [`404.html`](404.html) sends the old addresses of moved projects on to their new ones, with the rest of the path, the query and the fragment.

| Old address | New address |
|---|---|
| `nahuelgenchi.github.io/onsoku-advance/` | [`dreamports.net/play/sonic-advance/`](https://dreamports.net/play/sonic-advance/) |
| `nahuelgenchi.github.io/sonic-advance-dreamport/` | [`dreamports.net/play/sonic-advance/`](https://dreamports.net/play/sonic-advance/) |

Every other missing page shows a short "Page not found".
