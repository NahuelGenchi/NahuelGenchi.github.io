# nahuelgenchi.github.io

The root of Nahuel Genchi's GitHub Pages sites. It holds no site of its own: its [`404.html`](404.html) sends the old addresses of renamed projects on to their new ones, with the rest of the path, the query and the fragment.

| Old address | New address |
|---|---|
| `nahuelgenchi.github.io/onsoku-advance/` | [`nahuelgenchi.github.io/sonic-advance-dreamport/`](https://nahuelgenchi.github.io/sonic-advance-dreamport/) |

Every other missing page shows a short "Page not found".
